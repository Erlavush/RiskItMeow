# Project

**Risk It Meow**

Risk It Meow is currently a manual-feature Godot prototype. The active scene includes one player, an `8x8` room shell with four walls and a roof, a room-view orbit camera, a runtime furniture placement system, a camera-driven wall cutaway system, and a developer environment tuning panel. Future work is still added manually, one feature request at a time.

**Core Value:** Keep the project easy to extend by preserving a clean baseline and only adding explicitly requested features.

## Working Rules

- This repo is not following a source-porting roadmap anymore.
- Add one feature at a time from the current Godot baseline.
- Keep direct player movement unless the user explicitly asks to replace it.
- Keep the current room-view camera unless the user explicitly asks to change it.
- Keep the current runtime placement/inventory prototype unless the user explicitly asks to replace or remove it.
- Do not add cats, backend sync, multiplayer, or other unrelated legacy scope by default.
- Do not add backend, Firebase, shared-room, couple, or multiplayer systems unless the user explicitly asks for them.

## Useful Notes

- The live room is `8x8`, with `0.25` floor thickness, `0.25` wall thickness, four walls, and a roof.
- The active floor uses a dark-brown linen texture that is downscaled to `32x32`, repeated once per floor block, and randomly rotated per tile.
- Placement uses a browser-style left panel with `Inventory` and `Shop` tabs, category tabs, Build/Edit modes, save/load controls, and floor-finish switching.
- The active runtime catalog now uses one data-driven imported-item pipeline for the curated live items; the large FBX household pack remains archived by default until specific props are re-enabled one by one.
- Shop and inventory cards now use generated PNG thumbnails from `assets/ui/item_previews` instead of live runtime 3D preview scenes.
- Thumbnails are generated by [generate_item_previews.gd](/Z:/RiskItMeow/risk-it-meow/scripts/tools/generate_item_previews.gd).
- Placement supports floor items, wall-mounted windows, wall cutouts, gizmo drag, preview validity, double-click edit selection, move/duplicate/delete, and autosave.
- Room layouts persist locally in `user://room_layout.json`, including placed items, transforms, owned inventory totals, and floor finish.
- The editor 3D preview mirrors the locally saved room layout by reading `user://room_layout.json` through tool-mode preview logic.
- The developer panel can tune lighting, fog, glow, and post-adjustment live, persists locally in `user://`, and reapplies that saved preset in the editor preview.
- The developer panel includes persistent `Morning`, `Noon`, `Sunset`, and `Afternoon Cozy` sun presets.
- The room uses a first-pass Sims-style cutaway controller: camera-facing walls and the roof switch to render-only cutaway mode while preserving collisions and shadows.
- Windows use a lightweight sunlight workaround: sun-facing windows inject warm interior portal light plus a soft room bounce light.
- The `temporary/` pizzeria source tree is intentionally hidden from Godot scanning with `.gdignore` to avoid duplicate UID warnings while preserving old dependency paths.
- Curated live items and any future re-enabled props should go through the same data-driven imported-item catalog path so debug tuning and placement stay on one system.
- Local Godot executable paths are documented in [LOCAL_TOOLING.md](/Z:/RiskItMeow/risk-it-meow/LOCAL_TOOLING.md) and should be treated as the default project executables for editor and console runs.
