# Risk It Meow - Working Roadmap

## Project Overview

Risk It Meow is currently a fresh Godot prototype baseline. The active scene is intentionally minimal: one player, one visible floor platform, and one room-view orbit camera.

The repo is no longer following a source-porting roadmap. Future work is requested manually and added one feature at a time.

## Current Baseline

- Player controller is active
- Single orbit camera is active
- Floor platform is active
- Walls and ceiling are hidden
- Cats, build mode, and placement systems are removed from the live scene

## Rules For New Sessions

- Read [`.planning/STATE.md`](/Z:/RiskItMeow/risk-it-meow/.planning/STATE.md) and [`.planning/PROJECT.md`](/Z:/RiskItMeow/risk-it-meow/.planning/PROJECT.md) first.
- Do not assume any source-porting or parity work.
- Add one feature at a time from the current Godot baseline.
- Do not add backend, Firebase, shared-room, couple, or multiplayer systems unless explicitly requested.
- Do not reintroduce cats, build mode, walls, or roof unless explicitly requested.
