# Quick Task 260404-nn8

## Description

Add a developer environment tuning panel for lighting and post-processing.

## Scope

- Add a top-right `Developer` toggle button in the active scene.
- Show a collapsible runtime panel with live controls for scene environment values.
- Support practical world-tuning controls: light, warmth, shadows, ambient, exposure, brightness, contrast, saturation, fog, and glow.
- Keep the panel developer-facing and prevent placement clicks from leaking through hovered UI.
- Do not turn this into a player-facing settings screen.

## Tasks

1. Add a dedicated runtime developer panel script and hook it into `main.tscn`.
2. Bind UI controls to `WorldEnvironment` and `DirectionalLight3D` so changes apply immediately.
3. Add a reset-to-defaults action and prevent placement interaction while hovering developer UI.
