## Problem

The current placement browser is capable but still panel-driven. A quicker access layer would help players place common items or tools without repeatedly shifting attention across the full UI.

## Solution

Add an optional radial quick-build menu for favorites, recent items, and key build actions. Keep it additive to the existing browser instead of replacing the current workflow.
